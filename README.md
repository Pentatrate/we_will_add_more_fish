It has a dedicated post named `We Will Add More Fish` in the `ea-mods` forum

## How to install

1. Download zip:
   Either directly download the repository as a zip (**I recommend this**)

    [Download link](https://github.com/Pentatrate/we_will_add_more_fish/archive/refs/heads/main.zip)

    or download the "latest" release (The latest release may not have features added in later commits)

    ![Commits Since Release](https://img.shields.io/github/commits-since/Pentatrate/we_will_add_more_fish/latest)

    ![Screenshot to find releases](https://github.com/user-attachments/assets/2acbead3-fad3-476b-9525-43fb1d728cb6)

2. Unzip and place in `beatblock/Mods/` folder (where all the other mods are)

    **!!!Reminder!!!**: Make sure the mod.json file is in `beatblock/Mods/we_will_add_more_fish/mod.json` and **NOT** `beatblock/Mods/we_will_add_more_fish/we_will_add_more_fish/mod.json`

3. Relaunch modded beatblock
